# Observability tooling decision

**Proposed baseline for the beta build, live feedback period and production release.** Instrument the factory and its generated app template with OpenTelemetry and use Azure Monitor as the operational backend. Use the protected factory verifier and a versioned evaluation suite to assess agent quality. Langfuse and LangSmith are optional tools for the engineering team. The estimate assumes the Azure baseline.

| Question | Tool and evidence |
| --- | --- |
| Why is a preview late or a released app slow? | Application Insights shows the request and dependency trace. Instrument the controller, queue consumer, model gateway, retrieval broker and verifier. Capture the optional discovery subagent as a child operation when invoked. Keep waiting for sponsor approval distinguishable from waiting for a worker. [Application Insights](https://learn.microsoft.com/en-us/azure/azure-monitor/app/app-insights-overview) |
| What changed and who responds? | Query redacted events by attempt or revision in Log Analytics. Azure Monitor alert rules detect the stalled queue, evidence mismatch or unhealthy canary. Action Groups notify the assigned operator. The release controller owns the rollback decision under the approved policy. [Azure Monitor Action Groups](https://learn.microsoft.com/en-us/azure/azure-monitor/alerts/action-groups) |
| Did a change to Claude's instructions or retrieval improve outcomes? | Run the current and candidate configurations on the same versioned, labeled cases in protected CI. Compare missed access changes, unnecessary escalations, retrieval citations, cost and reviewer time. Save results alongside the configuration revisions. The verifier and release policy use durable gate records even when traces are sampled. |

## When to add a specialist tool

**Langfuse** is the first candidate if the feedback team spends significant time joining agent traces, annotating mistakes and comparing dataset runs. It documents a TypeScript Claude Agent SDK integration and self-hosting on Azure. Self-hosting adds services, storage, upgrades and backup ownership. **LangSmith** also integrates with the Claude Agent SDK and supports datasets, experiments and human review. Choose it for the trial if an approved instance, license and operating team already exist. [Langfuse Claude SDK integration](https://langfuse.com/integrations/frameworks/claude-agent-sdk-js) · [Langfuse self-hosting](https://langfuse.com/self-hosting) · [LangSmith Claude SDK integration](https://docs.langchain.com/langsmith/trace-claude-agent-sdk) · [LangSmith evaluation](https://docs.langchain.com/langsmith/evaluation)

During feedback, use one synthetic retrieval mistake and one unsafe policy classification to compare the Azure workflow with one candidate tool. Record how long a reviewer takes to locate, label and replay each failure, which steps need manual work, and the incremental operating cost. Add the tool only if the team can demonstrate a review benefit and agree on the operator, approved network path and data controls.

For either trial, a trusted exporter sends only allowlisted fields such as attempt ID, tool name, timing, token counts, version and outcome. Use synthetic fixtures when reviewers need to inspect inputs or outputs. Verify exported payloads exclude real prompts, source code, retrieved documents, credentials and tool arguments. Keep the sandbox's existing egress boundary and the protected release-evidence store. The [observability presentation spec](../presentation/OBSERVABILITY_AND_OPERATIONS_SPEC.md) defines the incident drill and release-decision example.
